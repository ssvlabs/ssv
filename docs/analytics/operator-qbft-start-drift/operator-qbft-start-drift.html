Operator QBFT‑start drift within a cluster

For a proposer duty, how far apart — in when into the slot they start QBFT — a cluster's operators sit. Two lenses: the full spread (fastest vs slowest), and the practical spread that actually gates consensus (dropping the operators that fall out of quorum).

What the numbers are

Two spreads, and how to read the bars

Each operator's QBFT start is its round‑1 proposal time into the slot on the duties it leads (the leader rotates, so every operator is sampled). Every gap is measured from the fastest operator's typical start. On each chart, the tick is the median (typical) gap and the bar runs to the p95 (worst‑case) gap — so a short tick with a long bar means "usually tight, occasionally wide."

Full spread = fastest vs the slowest operator. Practical spread = fastest vs the slowest operator that still joins the quorum — QBFT needs only 2f+1 of n operators, so the f slowest fall out and don't gate consensus (for a 4‑op cluster that's dropping the single slowest; for 7‑op, the two slowest).

Method & caveats

  • Metric. Per operator, its round‑1 proposal time into slot on duties it led (leader = committee[slot mod n]). Gaps are relative to the fastest operator's median. Reliable only where every operator led ≥5× — the 85 higher‑volume clusters, which together handle 97.7% of all proposer duties. The ~100 unmeasured clusters mostly run 1–2 validators and propose <2.5% of the time — each operator would need years to lead 5 duties, so rotation can't reach them at any window.
  • Quorum. SSV needs 2f+1 of n=3f+1 operators, so f can fall out. Practical spread drops the f slowest on each statistic — the typically‑slowest for the median, the worst‑on‑a‑bad‑day for the p95 — since on any given duty it's whoever is slowest that misses quorum.
  • What it includes. QBFT start = slotStart + ProposerDelay + block‑fetch, so the gap blends clock skew, ProposerDelay differences, and CL/MEV block‑fetch time. Times are the Exporter's receive‑times; within a cluster's gap the per‑operator network path largely cancels.
  • p95 is noisy. With 5–40 leads per operator, p95 ~ the worst duty — treat single large p95 values (e.g. an operator's 2.9s) as "seen at least once," not a stable rate.
  • Read the tail. Median cluster gap is ~112ms and 80 of 85 clusters are under 200ms typically. The concern is the handful whose practical spread stays wide.
